# Checkpoint 4, Statistical Computing with R & Python (FIAP)

Temas escolhidos: Probabilidade e a Inteligência Artificial, e Distribuição Normal e a Inteligência Artificial.
Aplicação na área de Logística: previsão de atraso em entregas a partir de uma base simulada.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `apresentacao_cp4.pdf` | Entregável 1, parte escrita em PDF com 13 slides |
| `codigo_cp4.py` | Entregável 2, código-fonte em Python |
| `codigo_cp4_colab.ipynb` | Mesmo código em notebook, para rodar no Google Colab |
| `apresentacao_cp4.pptx` | Versão editável dos slides, com notas do orador |
| `roteiro_apresentacao.md` | Roteiro da apresentação oral, com a fala de cada integrante |
| `Roteiro_Simples_Apresentacao.docx` e `.pdf` | Explicação do trabalho em linguagem de ensino médio |
| `Checkpoint4_Documentacao_FIAP.docx` e `.pdf` | Documentação do trabalho no padrão visual da FIAP, gerada pela skill `fiap-doc` |
| `resumo_checkpoint4.docx` | Primeira versão do resumo, sem a identidade visual da FIAP |
| `fontes/` | Fonte Montserrat, usada no padrão visual da FIAP. Instale antes de editar o .pptx |
| `graficos/` | Gráficos gerados pela execução do código |
| `base_entregas_simulada.csv` | Base simulada gerada na execução |

## Como executar

```bash
pip install numpy pandas matplotlib scipy
python codigo_cp4.py
```

A semente do gerador está fixa em 42, portanto a execução é reprodutível.
